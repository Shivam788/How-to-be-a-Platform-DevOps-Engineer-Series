# Series Overview

This series is a practical playbook for learning to think and work like a Platform / DevOps Engineer in enterprise environments.

The goal is to help engineers, especially those who are new to the field, understand not only what to build but also why it matters and how to implement it in a production-ready way.

The series is based on real platform engineering principles used in Azure-based enterprise environments, including landing zones, hub-spoke networking, governance, automation, and secure delivery pipelines [web:53][web:30].

## Why this series exists

Many engineers can follow a tutorial, but struggle to understand how a real enterprise platform is planned from scratch.

This series is designed to close that gap by showing:
- how to think about platform design,
- how to break a large system into manageable parts,
- how to build with security and governance in mind,
- and how to automate everything in a repeatable way.

## Who this series is for

This series is intended for:
- Junior engineers who want a structured starting point.
- DevOps engineers moving into platform engineering.
- Cloud engineers working with Azure.
- Architects who want a practical delivery-oriented view.
- Teams building secure enterprise workloads in regulated environments.

## What you will learn

By following this series, you will learn how to:
- design an Azure landing zone,
- plan network and subscription boundaries,
- create hub-spoke connectivity,
- apply governance using Azure Policy,
- use Terraform in a modular way,
- build Azure DevOps YAML pipelines,
- deploy workloads securely on OpenShift,
- and build platforms that are cost-aware, compliant, and production-ready.

## How to use this series

Follow the documents in order.

Recommended reading path:
1. Read the architecture at a high level.
2. Review the prerequisites.
3. Follow the step-by-step implementation.
4. Study the security and governance model.
5. Review Terraform and CI/CD automation.
6. Read the technical challenges and lessons learned.

## Learning approach

Each section is written using the same pattern:
- What to do.
- Why it matters.
- How to do it.
- What can go wrong?
- What to validate before moving forward.

This makes the series useful both as a learning guide and as a project reference.

## Expected outcome

By the end of the series, you should be able to think like an enterprise platform engineer and understand how to build a secure, scalable, and well-governed Azure foundation from scratch.

The intention is not only to learn tools, but to learn the engineering mindset behind them.
